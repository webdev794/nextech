# Tasks Done Today

- **Temu-style seller shipping:** sellers choose NexTech collects & delivers / ship it themselves / ship with a NexTech label; ship-from addresses, shipping templates (states, transit days, fee), working-day and holiday calendar, free-shipping rule, ship-by / arrival dates at checkout, confirm shipment with carrier + tracking (format check, max 3 edits, bulk edit), customer "Confirm received", payout hold released after delivery + return window. Admin sees seller packages on each order and can edit tracking / mark delivered / lost.
- **Admin can turn off "NexTech collects & delivers"** (Available / Shown but unselectable / Hidden); sellers on it get a notice and can't add new products until they set up their own shipping.
- **Built-in shipping labels:** a seller's label request produces a PDF instantly from admin label templates (4×6 thermal / A4 — ship-from, ship-to, order reference, contents). Sellers can switch layout or discard any time, then add tracking when they ship. Admin manages templates (preview, default, active) and can replace any label with their own PDF; with no active template, requests wait for an admin upload. Optional courier-API mode kept for real paid labels.
- **India market (₹) alongside the US ($):** every country is its own store — its own products, sellers, NexTech stores, riders, currency, fees, commission, payout limits and rider pay. Shoppers only see and buy their country's products; carts and orders are single-country.
- **India compliance:** GST-inclusive MRP pricing (HSN code, GST rate 0/3/5/18/40%, country of origin, manufacturer required from Indian sellers); GST shown inside order totals; TCS 0.5% (GST sec. 52) and TDS 0.1% (sec. 194-O) withheld from Indian sellers' sales and reversed on refunds; grievance officer shown in the India footer; Indian states, holidays and carriers (Delhivery, Blue Dart, DTDC, India Post, Ekart, XpressBees, Shadowfax).
- **Currency switch in the admin top bar** ($ USD / ₹ INR): Dashboard (numbers + charts), Orders, Products, Sellers, Riders, Stores and Settings → charges all show only the selected country. Default country setting (e.g. India-only operation), store Country field, "Sold in" country on NexTech products.
- **Storefront country** is picked automatically (device time zone on first visit, then the delivery pin's country) with a header picker to override; prices, checkout, state list, PIN/ZIP label and tax display follow the country.
- Each amount is shown in its own country's currency format everywhere (storefront, Seller Center, admin, rider app, server messages) — `₹1,23,456.00` / `$1,234.56`. No currency conversion: sellers price products in their own currency, and admin sets charges separately for each currency.
